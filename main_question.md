# Main Question

How can we design a Data Science and AI Society course that takes beginners from basic Python to practical data analysis, visualization, AI-assisted workflows, and independent projects they can confidently explain and extend?

## Reference Sub-Questions

### Course Direction and Learning Path

- What should a complete beginner be able to build, understand, and explain by the end of the course?
- How should the course move from Python basics into real data science without overwhelming learners?
- What concepts are essential before introducing AI and machine learning: variables, types, lists, dictionaries, functions, files, data frames, plotting, or statistics?
- What should each session produce: notes, runnable code, mini-tasks, a challenge, a small project, or a portfolio artifact?
- How can the course balance explanation, live coding, debugging, exercises, and independent exploration?
- Which topics should be taught as foundations, and which should be left as optional advanced paths?
- How can the society keep the course useful for both absolute beginners and members who already know some programming?

### Python and Programming Foundations

- What are the most important Python ideas for data science students to master first?
- How can exercises like calculators, flight-route data, odd/even organizers, and type guessing become more realistic data problems?
- When should students move from simple scripts to reusable functions, modules, notebooks, or small applications?
- How should debugging, error messages, testing, and code reading be introduced early?
- What coding habits should be taught from the beginning: clear names, comments, formatting, small functions, and reproducible examples?
- How can sessions make students comfortable with terminal commands, package installation, virtual environments, and project folders?

### Data Science Skills

- What datasets should students use after toy examples: public health, sports, finance, transport, climate, music, social media, or local society data?
- How should students learn the full data workflow: asking a question, collecting data, cleaning it, exploring it, visualizing it, modeling it, and communicating results?
- What should students learn about messy data, missing values, outliers, wrong types, duplicate rows, and biased datasets?
- How can visualizations teach students to think critically instead of only producing attractive graphs?
- What are the best first projects for understanding pandas, NumPy, matplotlib, seaborn, and basic statistics?
- How can each project lead to a clear written insight rather than only a code output?

### AI Tools and Modern Workflows

- How should tools like Gemini, ChatGPT, APIs, and coding assistants be used responsibly in a beginner course?
- What should students learn about prompting, checking AI answers, debugging generated code, and avoiding blind copy-paste?
- How can AI tools help with research, code explanation, data cleaning, visualization ideas, and project planning?
- When should students use an AI model, and when should they solve the problem manually to build understanding?
- What practical API projects would be useful: Spotify data, recommendation systems, text summarization, chatbot prototypes, or dataset enrichment?
- How can the course teach limitations of AI, including hallucinations, privacy, bias, cost, and reproducibility?
- What does the Turbo Quant KV Cache paper (Google) reveal about how large language models store and reuse attention state, and how does understanding KV caching help students reason about LLM inference cost and speed?

### Community, Projects, and Portfolio

- How can the society turn workshop sessions into member-led projects and collaboration?
- What structure should member folders follow so projects are easy to review, continue, and showcase?
- What makes a good beginner portfolio project in data science or AI?
- How should members document their work: problem statement, dataset source, method, results, limitations, and next steps?
- What project themes would be exciting for members: Spotify analytics, campus data, games, finance, sports prediction, environmental data, or automation?
- How can advanced members mentor beginners without taking over their projects?
- How can the course end with a demo day, written report, GitHub portfolio, or society showcase?

## Current Course Materials

- `Session_1/`: Python basics workshop.
- `Session_2/`: programming challenges using calculators, flight data, type guessing, and organizers.
- `Session_4/`: Gemini setup, NPM/Node notes, and Spotify API notes.
- `Session_5/`: data visualization with pandas, matplotlib, seaborn, and the Iris dataset.
- `Members/`: space for member work and portfolios.
